# jsv8

`jsv8` is a project built around the V8 JavaScript engine.

This repository contains the source code, documentation, examples, and supporting resources for the jsv8 project.

## Features

- V8 JavaScript engine integration
- Lightweight and easy to integrate
- JavaScript execution support
- Suitable for embedded JavaScript use cases
- Cross-platform development friendly
