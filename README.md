### Key Calculations

#### CPM - Cost Per Mille

Calculates the advertising cost per 1,000 impressions.

```text
CPM = (Cost / Impressions) x 1,000
```

#### CPC - Cost Per Click

Calculates the average advertising cost for each click.

```text
CPC = Cost / Clicks
```

#### CTR - Click-Through Rate

Calculates the percentage of impressions that result in clicks.

```text
CTR = (Clicks / Impressions) x 100
```

#### CPA - Cost Per Acquisition

Calculates the average advertising cost for each acquisition or conversion.

```text
CPA = Cost / Conversions
```

#### Conversion Rate

Calculates the percentage of clicks that generate conversions.

```text
Conversion Rate = (Conversions / Clicks) x 100
```

#### ROAS - Return on Ad Spend

Calculates the revenue generated relative to advertising spend.

```text
ROAS = Revenue / Advertising Cost
```

#### Impressions

Estimates the number of impressions from media cost and CPM.

```text
Impressions = (Cost / CPM) x 1,000
```

### 主要計算功能

#### CPM - 每千次曝光成本

計算每 1,000 次廣告曝光所需要的成本。

```text
CPM = (廣告成本 / 曝光次數) x 1,000
```

#### CPC - 每次點擊成本

計算每次廣告點擊的平均成本。

```text
CPC = 廣告成本 / 點擊次數
```

#### CTR - 點擊率

計算廣告曝光後產生點擊的百分比。

```text
CTR = (點擊次數 / 曝光次數) x 100
```

#### CPA - 每次轉換成本

計算取得每個轉換或客戶所需要的平均廣告成本。

```text
CPA = 廣告成本 / 轉換次數
```

#### Conversion Rate - 轉換率

計算點擊後產生轉換的百分比。

```text
轉換率 = (轉換次數 / 點擊次數) x 100
```

#### ROAS - 廣告支出回報

計算廣告收入相對於廣告支出的比例。

```text
ROAS = 廣告收入 / 廣告成本
```

#### Impressions - 曝光次數

根據廣告成本及 CPM 推算曝光次數。

```text
曝光次數 = (廣告成本 / CPM) x 1,000
```
